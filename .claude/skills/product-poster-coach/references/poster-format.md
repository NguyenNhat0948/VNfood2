# ポスター書式・印刷仕様（A4縦）

成果物は **A4縦1枚のHTMLポスター**（`poster.html` ＋ `poster.css`）。ブラウザで開いて確認し、印刷ダイアログから**A4縦のPDF**にして入稿・持参する。デザインは Apple/liquid-glass 系（NAVY/ブルー基調）で、印刷にそのまま耐えるよう作られている。

## ファイルと置き方
1. `assets/poster_template.html` を作業ディレクトリに `poster.html` としてコピー
2. `assets/poster.css` を同じ階層にコピー（`poster.html` が `poster.css` を参照）
3. 画像は同階層の `figures/` に置く（例: `figures/hero.png`, `figures/arch.png`）
4. 記入例 `assets/poster_sample_moraeru.html` を開くと完成イメージが分かる（文体・分量の基準）

## 穴埋めのルール
- `{{...}}` を対話で確定した文言に置き換える。**新情報を勝手に足さない**（受講生の言葉で）
- 見出し・タグラインは**価値から・結論文**（体言止め回避）。1文40字以内が目安
- 画像プレースホルダ `<span class="ph">…</span>` は、用意できたら `<img src="figures/xxx.png" alt="…">` に差し替える
- 数字は小さくてOK・**「0」は避ける**。`{{XX}}` を実数に
- 🐧 のヒント（各Phase）に沿って埋めると外さない

## 必須3点（これが無いと成立しない）
1. **03 検証実績**（数字・使ってくれた人の声。0は避ける）
2. **05 失敗と学び**（通用しなかった1つ＋学び）
3. **顔写真＋連絡先QR**（採用担当が辿り着けるように）

## QRコードの作り方（簡易）
- プロダクトURL・連絡先URL（メール/SNS）をQRにする。オンラインのQR生成やライブラリで作り、`figures/` に置いて `.qr__code` の中身を `<img>` に差し替える
- プライバシー配慮で連絡はSNS/フォーム推奨

## 印刷（PDF化）手順
1. `poster.html` をブラウザ（Chrome/Safari 推奨）で開く
2. `Cmd/Ctrl + P`
3. 用紙: **A4** / 向き: **縦(portrait)** / 余白: **なし**
4. 詳細設定 → **背景のグラフィック: ON**（glassの背景を出すため必須）
5. 「PDFに保存」→ カラー印刷して当日持参

## 注意
- `poster.css` は A4（210×297mm）に最適化。要素を増やしすぎると2ページに溢れる → 1枠1メッセージで収める
- フォントはGoogle Fonts（Noto Sans JP / JetBrains Mono）をCDN参照。オフライン印刷でも文字は出るが、確実にするなら事前にブラウザで一度開いてキャッシュしておく
- 画像は解像度不足だと印刷で粗くなる。スクショ・図は大きめ（横1000px以上目安）で用意
